# One shared catalogue, each user's own collections

The app started for one person and is opening to a few trusted users. Funkos (with their categories, series and images) form one catalogue shared by everyone, while collections, items and tags belong to one user and only that user sees them, admins included. A funko is the same for everyone who owns it, so sharing it avoids every user typing and photographing the same figure; lists are personal, so they stay private.

A member's new funko is a submission: usable in their own collections at once, visible to others only after an admin approves it (or merges it into an existing funko). Only admins edit catalogue funkos.

## Considered Options

- **Everything shared** (one collection everyone edits): rejected, it makes "Owned" meaningless for more than one person.
- **Each user's own catalogue**: rejected, it duplicates every funko and its images per user and leaves nothing to submit.
